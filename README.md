# DBD Bodyguard Challenge App

This tool is a simple web app for the DBD challenges like the famous **Bodyguard Challenge**.

## Usage

Put the pictures of the survivors you want to use in the tool into the folder `src/pictures`. The tool automatically generates the grid
according to the pictures in that folder.

Run the tool using `npm run app`
